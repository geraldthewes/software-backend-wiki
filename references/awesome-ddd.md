## Abstract

A curated list of Domain-Driven Design (DDD), Command Query Responsibility Segregation (CQRS), Event Sourcing, and Event Storming resources. This repository serves as a comprehensive collection of learning materials, tools, books, courses, videos, community resources, blogs, sample projects, libraries, and frameworks related to DDD and associated patterns.

The awesome-ddd list includes resources organized by category:
- Books (including Evans' "Blue Book", Vernon's "Red Book", and various specialized topics)
- Free eBooks and guides
- Training courses and workshops
- Video collections and conference recordings
- Community resources (mailing lists, forums, Discord groups, Stack Exchange tags)
- Blogs and newsletters from DDD practitioners
- Sample projects in multiple programming languages (Go, .NET, Haskell, Idris, JavaScript/TypeScript, JVM languages, PHP)
- Libraries and frameworks for implementing DDD, CQRS, Event Sourcing
- Podcasts, interviews, and conference talks
- User groups and local communities
- Tools for DDD practice (event storming, context mapping, etc.)

This resource represents a community-driven effort to collect and organize high-quality DDD learning materials, making it easier for developers to find relevant resources for studying and implementing Domain-Driven Design principles.
